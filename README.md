## 🚀 Featured Engineering Projects

### 1. [AeroDispatch — Cloud-Native Logistics & Fleet Telemetry](https://github.com/AnilPrajapati543543/aero-dispatch)
> **Production-grade multi-role logistics dispatch, real-time milestone tracking, and driver allocation system.**

- 🌐 **Live Web Application:** [https://aerodispatch.site](https://aerodispatch.site)
- 🛠️ **Architecture:** AWS Amplify & S3 (React 19 SPA), FastAPI (Python 3.12), Amazon DynamoDB, AWS Cognito User Pools, Amazon S3, and Amazon SNS.
- ✨ **Key Highlights:**
  - **Trio Role Experience**: Dedicated portals for Customers (booking & live map tracking), Delivery Captains (route run sheets & proof verification), and Operations Admins (fleet allocation & multi-hub oversight).
  - **Verified Delivery Proof**: Doorstep delivery verification with OTP validation and smartphone camera photo uploads.
  - **Customer Review System**: Verified 1–5 star rating and feedback engine with strict role separation.
  - **Automated CI/CD**: GitHub Actions workflow running 44 automated backend test cases and frontend build verifications on every release.
